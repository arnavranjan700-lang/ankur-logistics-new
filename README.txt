ANKUR LOGISTICS — NEW WEBSITE DEMO

How to preview:
1. Extract the ZIP file.
2. Open the extracted Ankur_Logistics_New_Website folder.
3. Double-click index.html.

Files:
- index.html: website structure and content
- styles.css: responsive design
- script.js: sample tracking and freight calculator
- assets/: logo, truck hero image, and gallery photos

Important:
- Shipment tracking uses demo records only (AL123456, AL100200, AL555777).
- It is not connected to live shipment/GPS data or the admin database.
- Calculator is an indicative estimate using the supplied demo rates:
  PTL ₹15/kg, minimum ₹1,007; Parcel ₹20/kg, minimum ₹500; FTL ₹25/kg, minimum ₹6,500; special handling +₹775.
- This ZIP does not automatically change or publish the live website.
- Confirm final shipping charges with Ankur Logistics before accepting a shipment.
